# Polybound

A tactical two-player polyomino game on a 14×14 grid. Play a friend on the same screen, a friend online, or an AI (Easy, Medium, Hard). New players can start with a five-lesson interactive tutorial.

## Run locally

**Prerequisites:** Node.js

1. Install dependencies: `npm install`
2. Start the dev server: `npm run dev` (http://localhost:3000)

Other scripts: `npm test` runs the unit tests (Vitest), `npm run typecheck` runs TypeScript, and `npm run build` makes a production build in `dist/`.

## Rules in brief

- Your first piece must touch your home row (Crimson: bottom, Cobalt: top).
- Each new piece must touch your own pieces corner to corner, never edge to edge. The exception is the central 4×4 **neutral zone**, where your own pieces may share edges.
- **Bridge pieces** have dashed squares that can hop over opponent squares without capturing them.
- A player with no legal move is skipped. The game ends when neither player can move, when someone resigns, or when a clock runs out.
- Scoring: +1 per square you place, +1 per square in the neutral zone, +2 for each opponent piece that ends up enclosed (every edge touching a square or the board edge, whoever closed the last gap), and +3 for placing every piece.

## Controls

Click or tap a piece, then click or drag on the board to place it.
`R` or right-click rotates, `F` flips, `Esc` deselects, `U` undoes, and `H` toggles the move-hint diamonds.
Keyboard only: tab to a piece in the tray, press Space, move it with the arrow keys and press Enter.

## Features

- **Saved games:** a game against the AI or a local friend is saved in the browser and can be resumed from the menu.
- **First move:** choose who starts, or alternate between games. Win/loss records are kept per mode.
- **Online play:** one player creates a room and shares the 5-letter code or invite link. Moves travel directly between the two browsers over WebRTC ([PeerJS](https://peerjs.com)). Only the initial matchmaking goes through PeerJS's free public server. To use your own [PeerServer](https://github.com/peers/peerjs-server) instead, build with `VITE_PEER_SERVER=https://your-host/path`. Some strict networks block direct connections; there is no relay (TURN) server.
- **Offline and installable:** production builds include a web app manifest and a service worker (generated by the plugin in `vite.config.ts` from `pwa/sw.js`), so the game can be added to a home screen and works offline after the first visit.
- **AI in a Web Worker:** the AI searches off the main thread, so the page stays responsive while it thinks.
- **Accessibility:** Crimson squares carry a dot and Cobalt squares a ring, so colour isn't needed to tell them apart. Moves and piece positions are announced to screen readers.

## Deployment

Pull requests run type-checking, tests and a build (`.github/workflows/ci.yml`). Pushes to `main` are published to sometimesfunctional.com/polybound/ by `.github/workflows/deploy.yml`.
